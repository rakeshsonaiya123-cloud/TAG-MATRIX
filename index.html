HTML Tags Reference

<!DOCTYPE html> HTML


          
Defines the document as HTML5. Must be the first line.

        

        

          
<html> HTML

          

          
Root element of the page. All content goes inside it.

        

        

          
<head> HTML

          

          
Contains meta info, title, links to CSS, etc.

        

        

          
<body> HTML

          

          
Visible content of the page goes here.

        

        

          
<h1> – <h6> HTML

          

          
Headings from largest (h1) to smallest (h6).

        

        

          
<p> HTML

          

          
Defines a paragraph of text.

        

        

          
<a> HTML

          

          
Creates a clickable link to another page or URL.

        

        

          
<img> HTML

          

          
Embeds an image. Use src for path and alt for description.

        

        

          
<ul>, <ol>, <li> HTML

          

          
Unordered (ul) and ordered (ol) lists with items (li).

        

        

          
<div>, <section>, <header>, <footer> HTML

          

          
Layout and semantic tags to structure your page.

        

        

          
<table>, <tr>, <th>, <td> HTML

          

          
Creates a table with rows (tr), header cells (th), and data cells (td).

        

        

          
<form>, <input>, <button> HTML

          

          
Creates forms for user input and submission.

        

      

    

    

      
CSS Properties Reference

      

        

          
color CSS

          

          
Sets the text color of an element.

        

        

          
background-color CSS

          

          
Sets the background color of an element.

        

        

          
font-size, font-family CSS

          

          
Controls text size and font type.

        

        

          
margin, padding CSS

          

          
margin adds space outside, padding adds space inside an element.

        

        

          
display: flex, grid CSS

          

          
Modern layout systems for arranging items in rows and columns.

        

        

          
border, border-radius CSS

          

          
Creates borders and rounded corners.

        

        

          
width, height CSS

          

          
Sets the size of an element.

        

        

          
text-align CSS

          

          
Aligns text: left, center, right, justify.

        

      

    

    

      
JavaScript Concepts Reference

      

        

          
let, const, var JS

          

          
Ways to declare variables. Prefer let and const.

        

        

          
function, arrow function JS

          

          
Defines reusable blocks of code. Arrow functions are shorter syntax.

        

        

          
array, map, filter JS

          

          
Arrays store lists; map and filter transform them.

        

        

          
DOM, querySelector JS

          

          
DOM lets JS interact with HTML. querySelector finds elements.

        

        

          
if, else JS

          

          
Conditional logic to run code based on conditions.

        

        

          
for loop JS

          

          
Repeats a block of code multiple times.

        

        

          
fetch (API calls) JS

          

          
Makes HTTP requests to get or send data from servers.
